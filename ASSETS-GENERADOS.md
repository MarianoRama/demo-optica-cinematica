# Imágenes del catálogo

Generadas con la herramienta integrada de imágenes el 28/09/2026, a partir de los dos armazones aportados por el usuario. Son vistas ilustrativas para esta demo, no fotografías verificadas de productos disponibles. Cada archivo contiene dos paneles iguales: frontal a la izquierda y tres cuartos a la derecha. La web los encuadra mediante CSS.

Archivos: `dist/assets/metal-catalogo.png` y `dist/assets/acetato-catalogo.png`.

## Prompt metal

Create ONE two-view catalog sprite asset of the gray metal eyeglass frame in the reference. Wide canvas, exactly two equal square panels side by side, edge-to-edge pure white #ffffff seamless background, no divider. LEFT HALF: straight-on front product photograph of this same gray browline rectangular semi-rimless frame. RIGHT HALF: three-quarter product photograph of exactly the same frame, with full temples visible. Center each object independently in its half at consistent scale, occupying 80% panel width, same vertical center. Preserve gray metal brow bar, rectangular transparent lenses, bridge, slim temples. Remove the acrylic base entirely. Only glasses and a very subtle soft shadow. No text, labels, logos, decorative scene, pedestal, platform or extra products. This is a two-state image sprite for a website product card; only one pair in each panel.

## Prompt acetato

Create ONE two-view catalog sprite asset of the brown rounded acetate eyeglass frame in the reference. Wide 2:1 canvas, exactly two equal square panels side by side, edge-to-edge pure white #ffffff seamless background, no divider. LEFT HALF: straight-on front product photograph of this same brown rounded full-rim frame. RIGHT HALF: three-quarter product photograph of exactly the same frame, with full temples visible. Center each object independently in its half at consistent scale, occupying 80% panel width, same vertical center. Preserve brown woodgrain-like acetate material, rounded silhouette, keyhole bridge and transparent lenses. Remove the acrylic base entirely. Only glasses and a very subtle soft shadow. No text, labels, logos, decorative scene, pedestal, platform or extra products. This is a two-state image sprite for a website product card; only one pair in each panel.
